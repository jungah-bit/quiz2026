Q2울산 EV 공장과 E-FOREST 센터가 협업하여 구현한, SDF 라운지의 AI 기반 공장운영 시스템은?

Q3울산 EV 혁신기술 발표에서 "인력 의존 및 작업 한계"라는 변화의 이유(WHY)에 대응하기 위해 제시된 해결 방향(HOW)은?

Q4상온발포충진재 자동화 적용으로 얻은 효과로 소개된 것은?

  2. 2Smart Co-Pilot
  3. 3Digital Twin
  4. 4RPA (Robotic Process Automation)

Q3In the presentation on innovative technologies at the Ulsan EV Plant, which approach (HOW) was proposed to address "manpower dependence and work limitations" as a reason for change (WHY)?

  1. 1Quality automation
  2. 2Assembly automation (correct)
  3. 3Logistics automation
  4. 4Data integration

Answer2Assembly automation

ExplanationUnder this reason for change (WHY), the problem was described as a "continuing burden of high-difficulty, repetitive work." The proposed approach (HOW) was assembly automation, aiming for "maximum automation of high-difficulty, repetitive work → high productivity and reduced work burden."

Q4What benefit was presented as a result of automating the room-temperature expanding foam filler process?

  2. 2Doubled production speed
  3. 3Reduced weight by 10%
  4. 4Reduced paint defect rate by 50%

Answer1Reduced rear-seat noise by 2–3 dB

ExplanationWith 100% automated application and a system that inspects every unit, rear-seat noise was reduced by 2–3 dB. This improved the vehicle's NVH (noise, vibration, and harshness) performance.

Q7What were presented as the two pillars of the 'Two-Track Strategy' being pursued to get the Data Flywheel up and running early?

  1. 1Advancing the in-house autonomous driving model + a global partnership with NVIDIA (correct)
  2. 2Building a standardized sensor system + building a Data Union
  3. 3Securing global mass-production capability + building a standardized sensor system
  4. 4Building a Data Union + securing global mass-production capability

Answer1Advancing the in-house autonomous driving model + a global partnership with NVIDIA

ExplanationThe Two-Track Strategy consists of advancing the in-house autonomous driving model (Atria AI) and a global partnership with NVIDIA. Options ②–④ are all combinations of the "three key elements for building the Data Flywheel's core foundation" (sensor standardization, Data Union, and global mass-production capability) that also appear in the presentation. These are a separate concept from the Two-Track Strategy.

Q8Which wireless communication method was ultimately adopted to ensure stable and secure communication between the vehicles and the control server during driverless transport?

  1. 1Built-in vehicle Wi-Fi
  2. 2Commercial carrier LTE
  3. 3Private 5G (correct)
  4. 4Satellite communication

Answer3Private 5G

ExplanationWi-Fi's connection quality degrades when many vehicles connect at once, and LTE passes through the carrier's network, which raises latency and security issues. As a result, Private 5G based on the in-house network was ultimately adopted.
